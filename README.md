## 📖 About the Project

Christmas.exe is an interactive Christmas greeting Single Page Application (SPA) designed to make holiday wishes more personal, creative, and memorable.

Instead of sending ordinary Christmas messages, users can experience a magical Christmas environment, decorate their own Christmas tree, and unlock personalized greetings created especially for them.

The application combines traditional Christmas elements with modern web development concepts to create a fun and engaging experience.

## ✨ Features

- 🎄 **CSS Christmas Tree:** A beautifully animated Christmas tree created using CSS.
- ❄️ **Animated Snowfall:** Continuous snowfall for a magical winter atmosphere.
- 💡 **Christmas Lights:** Glowing and blinking decorative lights.
- 🎁 **Interactive Gift Box:** Animated gift-opening experience with a surprise message.
- 🎅 **Santa's Surprise:** A personalized Christmas experience.
- 💌 **Personalized Greetings:** Special Christmas messages based on the recipient.
- 💻 **Developer-Themed Wishes:** Creative Christmas greetings inspired by Object-Oriented Programming (OOP) concepts.
- 🎶 **Background Music:** Optional Christmas music with playback controls.
- 🎉 **Celebration Effects:** Animated particles, sparkles, and festive effects.
- 📱 **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- 📲 **WhatsApp Sharing:** Share Christmas greetings with friends and family.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js (LTS version recommended)
- npm
- Git

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd christmas-exe
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```

## 📦 Production Build

To generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

The production-ready files will be generated inside the `dist` directory.

## 🌐 Deployment

The application is deployed using **Vercel**.

To deploy your own version:

1. Fork or clone this repository.
2. Import the repository into Vercel.
3. Select Vite as the framework.
4. Set the build command to `npm run build`.
5. Set the output directory to `dist`.
6. Click Deploy.

Your application will be available through a public URL.
